# Stopwatch Web Application – Task 02 ⏱️

This project is a **Stopwatch Web Application** developed as part of **Task 02** for the **Web Development Internship at SkillCraft Technology**.

## 🚀 Features
- Start, Pause, and Reset stopwatch functionality
- Lap time recording and tracking
- Retro Synthwave UI with neon glow effects
- Responsive and user-friendly design

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6)
- CSS3 (Glassmorphism + Retro UI)

## 📌 Learning Outcomes
- React state management using hooks
- Handling intervals and stopwatch logic
- Implementing lap tracking dynamically
- Creating modern UI with CSS effects
